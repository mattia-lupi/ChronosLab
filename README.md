# ChronosLab


ChronosLab is a numerical linear algebra software framework designed for high-
performance linear system and eigenvalue search based on a MEX/C++ algebraic 
multigrid (AMG) preconditioning technique.



## PREREQUISITES
- MATLAB (R2018b or later)

## BUILD & INSTALLATION
- Start MATLAB and navigate to the repository root directory:
   - cd /path/to/ChronosLab
- Execute the build script to compile MEX binaries and configure paths:
   - compileAll
- Initialize the repository and add the repository to MATLAB path
   - initChronos
